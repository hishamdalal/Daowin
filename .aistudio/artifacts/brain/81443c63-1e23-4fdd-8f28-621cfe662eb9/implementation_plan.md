# دوّن (NoteCraft) — تطبيق الملاحظات المتقدم ثنائي العرض مع المزامنة والأوفلاين

تطبيق تدوين وتنظيم معرفي احترافي مصمم وفق مبادئ **Material Design 3** بنزعة باستيلية عضوية دافئة وتجربة عربية أصيلة (RTL-First). يجمع بين شاشات تصفح الملاحظات الملونة، ومحرر Markdown مباشر مع شريط أدوات عائم، ومعاينة منسقة غنية، وبحث هرمي متقدم في الأقسام والوسوم، وإدارة تذكيرات دقيقة قابلة للتثبيت، مع دعم كامل للوضع الداكن (Dark Mode) وأولوية قصوى للعمل دون اتصال بالإنترنت (Offline-First) عبر IndexedDB والمزامنة الفورية والتلقائية.

---

## مراجعة المستخدم والقرارات المؤكدة (User Review & Confirmed Decisions)

> [!IMPORTANT]
> تم تأكيد الخيارات المحورية الثلاثة التالية من قِبل المستخدم عبر الاستيضاح المسبق:
> 1. **استراتيجية التخزين دون اتصال**: اعتماد **Local-first IndexedDB** مع محاكاة المزامنة السحابية الذكية (Delta Sync)، والنسخ الاحتياطي التلقائي، وتصدير/استيراد بيانات JSON في أي وقت.
> 2. **السمة والمظهر اللوني**: دعم المزامنة مع سمة النظام الافتراضية للجهاز تلقائياً مع توفير زر تبديل سريع وسلس وفوري للوضع الداكن (Dark Mode) في الشريط العلوي وشاشة الإعدادات.
> 3. **تجربة فتح وتعديل المذكرة**: الفتح الافتراضي بنمط **المعاينة المنسقة الفاخرة (Formatted Preview)** مع تمكين التبديل بنقرة واحدة إلى **محرر Markdown المباشر** المدعوم بشريط الأدوات العائم.

---

## 1. نظرة عامة والمفهوم الأساسي (Overview & Core Concept)

- **ما يقدمه التطبيق**: بيئة عمل متكاملة وشاملة لصناع المحتوى، المهندسين، الباحثين، والطلاب تجمع بين بساطة بطاقات الملاحظات الملونة وقوة تحرير Markdown والمهام التفاعلية.
- **الشاشات الرئيسية المنفذة**:
  1. **شاشة المذكرات الرئيسية (All Notes Feed)**: تصنيف أفقي سريع، بطاقات ملاحظات باستيلية مثبتة بنسب تقدم المهام، مذكرات متسلسلة (معارض صور، مذكرات تقنية برمجية، قوائم مشتريات مع دوائر تحقق، اقتباسات مميزة، تسجيلات صوتية).
  2. **محرر ومستعرض الملاحظة (Note Editor & Formatted Preview)**: مسار هرمي، وسوم تفاعلية، معرض صور ومرفقات مصغرة، مبدل عرض (كتابة وماركداون vs معاينة وتنسيق)، شريط أدوات عائم كامل (H1, B, I, Checkbox, Bullet, Link, Code, Image, Quote)، ومنتقي ألوان الورقة الباستيلي.
  3. **البحث المتقدم والتصفية الذكية (Advanced Search & Filter Tree)**: شجرة الأقسام والشعب مع خيار "تضمين الأقسام الفرعية تلقائياً"، شبكة الوسوم النشطة، تصفية أنواع المرفقات (صور، مهام، مثبتة)، وفلاتر تدرجات الألوان الباستيلية مع معاينة حية فورية للنتائج وتظليل الكلمات المطابقة (`<mark>`).
  4. **لوحة التذكيرات والتنبيهات المتقدمة (Reminder Bottom Sheet)**: تثبيت دائم في شريط الإشعارات، مواعيد وأوقات سريعة، مؤقت تنازلي، تكرار مجدول متعدد المواعيد، ومعاينة بطاقة الإشعار لنظام Android.
  5. **لوحة الأقسام والمجلدات (Categories & Folders)**: استعراض شجري للأقسام الرئيسية والفرعية مع إحصائيات المذكرات.
  6. **شاشة الإعدادات ومركز المزامنة (Settings & Sync Center)**: فحص حالة الاتصال (Online/Offline)، زر المزامنة اليدوية الفورية، سجل المزامنة، وتصدير واستيراد النسخ الاحتياطية.

## 2. تجربة المستخدم والتصميم البصري (User Experience & Visual Identity)

### مسارات الاستخدام الرئيسية (Key User Flows)
1. **إنشاء وتحرير مذكرة جديدة**: النقر على زر الإجراء العائم (FAB) في أي وقت -> فتح المحرر المباشر -> اختيار القسم والوسوم ولون البطاقة -> الكتابة بواسطة وسوم Markdown وشريط الأدوات التفاعلي -> الحفظ التلقائي الفوري في IndexedDB.
2. **استعراض وتفاعل المهام**: التنقل السلس بين وضع الكود ووضع المعاينة المنسقة، إمكانية النقر على مربعات الاختيار في المعاينة لتحديث حالة المهمة فوراً دون الحاجة للدخول في وضع التحرير.
3. **التصفية المتشعبة والبحث الحي**: البحث النصي مع إبراز النتائج فوراً، حصر البحث على مسارات محددة (مثل `العمل > مشاريع 2025`) أو أنواع وسوم معينة.
4. **تفعيل الوضع الداكن**: تبديل مباشر بنقرة واحدة من الشريط العلوي، مع تطبيق ألوان داكنة مريحة للعين (`#1b1b21` للأسطح الأساسية مع تباينات هادئة للبطاقات الباستيلية الداكنة).
5. **الاستخدام دون اتصال والمزامنة**: إشعار هادئ عند انقطاع الإنترنت يوضح أن البيانات تُحفظ محلياً على الجهاز بالكامل، وعند عودة الاتصال أو فتح التطبيق تتم المزامنة التلقائية مع إمكانية الضغط على زر "مزامنة الآن".

### الهوية البصرية ولوحة الألوان (Visual Identity & Theme)
- **المعايير المعتمدة**: Material Design 3 مع نظام الألوان المخصص في ملفات التصميم:
  - **اللون الأساسي (Primary)**: `#461599` / `#5E35B1` للبنفسجي العميق والأزرار الرئيسية.
  - **الأسطح المحايدة الفاتحة (Light Surfaces)**: `#FBF8FF` لخلفية التطبيق، `#FFFFFF` للبطاقات، و `#EFECF5` للحاويات.
  - **الأسطح الداكنة (Dark Surfaces)**: `#121217` للخلفية الرئيسية، `#1E1E26` للبطاقات والحاويات، و `#2A2A36` للحاويات المرتفعة، مع خطوط مضيئة واضحة بنسبة تباين تتخطى 4.5:1.
  - **باليت الباستيل التعبيري للملاحظات**:
    - أصفر شروق مشرق / هادئ داكن للملاحظات ذات الأولوية.
    - بنفسجي خزامى للمذكرات التصميمية والرقمية.
    - أخضر نعناع منعش لمذكرات الاجتماعات والقرارات التقنية.
    - خوخي دافئ لقوائم المشتريات والميزانية.
    - أزرق سماوي للملخصات والكتب والمراجعات.
    - وردي كرزي ناعم للخواطر والأفكار الصوتية.
- **الطباعة والتخطيط العربي**: خط `Plus Jakarta Sans` للعناوين والأرقام، وخط `Be Vietnam Pro` / الخطوط العربية الحديثة للمتون مع ارتفاع أسطر فضفاض ومريح للقراءة.

## 3. القرارات التقنية وبنية تخزين البيانات (Technical Decisions & Trade-Offs)

```
┌────────────────────────────────────────────────────────────────────────┐
│                        دوّن NoteCraft Architecture                     │
├────────────────────────────────────────────────────────────────────────┤
│  UI Views Layer:                                                       │
│  [ Header & Brand ] ── [ Dark Mode & Sync Status Bar ]                 │
│  ├── View 1: All Notes Feed (Pastel Grid, Progress Checklist, Chips)  │
│  ├── View 2: Note Editor / Formatted Preview & Floating Toolbar        │
│  ├── View 3: Advanced Search & Dynamic Category Tree Filter            │
│  ├── View 4: Categories Manager                                        │
│  └── View 5: Settings, Data Backup & Sync Hub                          │
│  Modals Layer:                                                         │
│  └── Reminder Bottom Sheet (Pin to Status, Countdown, Multi-Times)     │
├────────────────────────────────────────────────────────────────────────┤
│  State & Logic Engine:                                                 │
│  ├── Notes Store (CRUD, Search, Tagging, Pinning, Coloration)          │
│  ├── Offline Sync Engine (IndexedDB Local-First + Delta Sync Queue)    │
│  ├── Theme Manager (System / Light / Dark toggle with persistence)     │
│  └── Notification / Reminder Mock Scheduler                            │
├────────────────────────────────────────────────────────────────────────┤
│  Storage Layer (IndexedDB / LocalStorage):                             │
│  ├── 'notecraft_notes' (Full note objects, attachments, markdown)      │
│  ├── 'notecraft_categories' (Hierarchical folder tree)                 │
│  └── 'notecraft_sync_meta' (Last synced timestamp, pending mutations)  │
└────────────────────────────────────────────────────────────────────────┘
```

1. **Local-First عبر IndexedDB**:
   - نستخدم واجهة تخزين محلية غير محدودة بالسعة الضيقة لـ LocalStorage لحفظ النصوص والصور والمرفقات الصوتية المضمنة دون بطء أو مشاكل اقتطاع.
2. **محرك المزامنة التلقائية واليدوية**:
   - فحص دوري لاتصال الشبكة (`navigator.onLine`).
   - عند إقلاع التطبيق، تشغيل عملية `autoSync()` لمزامنة العمليات غير المتزامنة.
   - إتاحة زر "مزامنة الآن" اليدوي مع مؤشر دوران وحالة وقت آخر مزامنة ناجحة.
3. **دعم PWA ومعايير تثبيت التطبيق**:
   - توفير ملف `manifest.json` وأيقونات التطبيق مع مراعاة متطلبات PWA والتثبيت على شاشات الجوال والحواسيب.

## 4. خطة التنفيذ المنهجية (Step-by-Step Implementation Steps)

1. **إعداد البنية التحتية ونظام الألوان المشترك**:
   - ضبط سمات Tailwind والوضع الداكن (`dark` class toggle) ومواءمة ألوان `index.css`.
   - إعداد طبقة التخزين المحلي `IndexedDB` (`src/services/db.ts`) والمزامنة `syncService.ts`.
2. **تجهيز البيانات الأولية الغنية باللغة العربية**:
   - إدراج كافة الملاحظات النموذجية الموضحة في صور واجهات المستخدم (خطة إطلاق المشروع، أفكار لتطوير الواجهة، ملاحظات اجتماع الفريق التقني، قائمة المشتريات، ملخص قراءة كتاب القيادة، فكرة بودكاست صوتي) مع كافة الصور والمرفقات.
3. **تطوير مكونات التصفح وشريط التنقل السفلي والعلوي**:
   - بناء الهيدر العلوي الموحد مع شعار دوّن، مبدل العرض الشبكي/القائمة، وزر التبديل للوضع الداكن، ومؤشر المزامنة.
   - بناء شريط التنقل السفلي المريح (المذكرات، الأقسام، البحث، الإعدادات) مع زر FAB العائم لإنشاء الملاحظات.
4. **بناء شاشة محرر الملاحظات المزدوج (Editor & Formatted Preview)**:
   - دعم التبديل السلس بين كود الماركداون والمعاينة المنسقة.
   - شريط الأدوات العائم بمختلف التنسيقات (العناوين، القوائم النقطية، صناديق المهام، الاقتباسات، الروابط، الصور، الأكواد).
   - منتقي ألوان البطاقات المخصص (Pastel Palette Selector).
5. **بناء نافذة التذكيرات التفاعلية (Reminder Bottom Sheet)**:
   - خيارات التثبيت الدائم، المواعيد المحددة السريعة، مؤقت العد التنازلي، وتكرار عدة أوقات يومية مع معاينة حية لشكل الإشعار.
6. **بناء شاشة البحث المتقدم والتصفية الهرمية**:
   - شجرة المجلدات المتفرعة، تبديل تضمين الأقسام الفرعية، الوسوم النشطة، فلترة المحتويات، والألوان مع تمييز الكلمات المفتاحية فوراً.
7. **بناء شاشة الإعدادات ومركز المزامنة والنسخ الاحتياطي**:
   - إمكانية تصدير كافة الملاحظات كملف JSON واستيرادها، وإجراء مزامنة يدوية، وتبديل السمة والخطوط.
8. **الفحص والتجميع النهائي**:
   - التحقق من خلو الكود من أي أخطاء عبر `compile_applet` وضمان عمل كافة الروابط والأزرار والمهام.
